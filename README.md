# LifeV24Care Hospital - Official Homepage Website (Mindmed Theme)

A responsive React single page application for **LifeV24Care Hospital**, located in Sector 34, Chandigarh. Built following the **Mindmed (by CodeBasket)** design structure.

## Features & Mapped Sections

1. **Top Bar**: Email (`info@lifev24care.com`), Location (`Sector 34, Chandigarh`), Social icons.
2. **Main Header**: Logo, Navigation menu, Phone number (`+91 172 247 0000`), "Book Now" cyan CTA button.
3. **Hero Section**: Eyebrow tag, round-the-clock headline, explore services CTA, hospital overlay visual.
4. **About Section ("Find Out About Us")**: Staggered dual doctor image layout, free consultation & happy patient badges, signature block.
5. **Services Section**: 6-card grid (Emergency Care, General Medicine, Laparoscopic Surgery, Gynaecology & Obstetrics, Diagnostic Lab, Paediatrics).
6. **Inside LifeV24Care Hospital Gallery**: Facilities carousel slider with captions.
7. **Doctors Section**: 4-card grid (Doctor details, specialty, photo, contact buttons).
8. **Video / Feature Section**: Video tour thumbnail with animated Play button triggering Video Modal + 6-item checklist.
9. **Testimonials Section**: 5-star rating, patient quotes slider with avatar selection.
10. **Blog Section**: 3-card grid (dates, category tags, Chandigarh SEO health articles).
11. **Footer**: Dark navy layout with logo, blurb, phone, departments list, helpful links, newsletter form, copyright bar.
12. **Appointment Booking Modal**: Triggers via all "Book Now" / "Book Appointment" buttons.

## Getting Started

### Local Development (with Node.js)
```bash
npm install
npm run dev
```

### Static Build for Production Hosting (cPanel, Hostinger, Vercel, Netlify)
```bash
npm run build
```
Upload the generated `dist/` directory files directly to your web server root (`public_html`).
